# Agent rules

- Never change this repository's visibility. It stays private until the owner makes it public themselves. Don't run
  `gh repo edit --visibility`, call the GitHub API's repo-update endpoint, or change it in the web UI.
- Never publish this repository's contents anywhere public: no public repo, fork, mirror or gist.
- The owner's name, nickname, account handle, and email address may appear where relevant, such as in the license,
  maintainer attribution, and installation instructions.
- Keep details about the owner's organizations and other projects private. Do not include private domains,
  credentials, or machine-specific paths. Use placeholders and portable paths, or read values from the current
  repository or session when needed.
