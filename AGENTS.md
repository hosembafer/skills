# Agent rules

- Never change this repository's visibility; only the owner makes that decision. Don't run
  `gh repo edit --visibility`, call the GitHub API's repo-update endpoint, or change it in the web UI.
- The owner has made this repository public. Committing, pushing, and opening PRs in this repository are allowed
  when requested. Do not create public forks, mirrors or gists unless explicitly requested.
- The owner's name, nickname, account handle, and email address may appear where relevant, such as in the license,
  maintainer attribution, and installation instructions.
- Keep details about the owner's organizations and other projects private. Do not include company branding, private
  domains, credentials, tokens, or machine-specific paths in repository content, commit messages, or PR descriptions.
  Use placeholders and portable paths, or read values from the current repository or session when needed.
