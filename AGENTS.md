# Agent rules

- Never change this repository's visibility. It stays private until the owner makes it public themselves. Don't run
  `gh repo edit --visibility`, call the GitHub API's repo-update endpoint, or change it in the web UI.
- Never publish this repository's contents anywhere public: no public repo, fork, mirror or gist.
- Keep repository content generic. Do not include identifying details about the owner, their organizations, or their
  other projects, including personal names, account handles, email addresses, private domains, or machine-specific
  paths. Use placeholders and portable paths, or read values from the current repository or session when needed.
